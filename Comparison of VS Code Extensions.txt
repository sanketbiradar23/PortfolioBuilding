### Comparison of VS Code Extensions

The VS Code extensions improved my coding experience in different ways. Python and Java extensions helped me write and run programs easily. Prettier automatically formatted my code and improved its readability. GitLens helped me understand the history of code by showing the author and previous changes. Live Share allowed two students to work on the same file in real time, making pair programming easier than screen sharing. Prettier changed my editing experience the most because it automatically organized my code. Python and Java extensions are useful for their respective languages, while Prettier, GitLens, and Live Share can be used in many projects. Overall, these extensions made coding easier, more organized, and more collaborative.
